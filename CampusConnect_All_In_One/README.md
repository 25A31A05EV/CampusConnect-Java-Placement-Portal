# CampusConnect – Smart Placement Management System

A student placement portal project package containing:
- Project overview and documentation
- Flowchart and algorithms
- Browser prototype (HTML/CSS/JavaScript)
- Java Spring Boot starter source
- GitHub upload instructions

## Quick browser demo
1. Open `browser-prototype/index.html` in Google Chrome.
2. Use the navigation to explore Dashboard, Students, Drives and Applications.
3. Add a student using the registration form. Demo data is stored in browser localStorage.

## Java backend starter
The Java source is a Spring Boot starter. It requires JDK 17 and Maven.
From `java-source`, run:
    mvn spring-boot:run
Then open http://localhost:8080

## Important scope note
The browser prototype is a front-end demonstration using local browser storage. The Java folder is a starter backend, not a production-ready deployment. Add authentication, validation, database configuration and automated tests before real use.
