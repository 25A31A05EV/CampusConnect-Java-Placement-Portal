# CampusConnect – Smart Placement Management System

## Project Overview

CampusConnect is a Smart Placement Management System designed to simplify and organize the campus placement process. It provides a centralized platform for managing student information, placement drives, eligibility criteria, and application tracking.

The system helps students stay informed about placement opportunities and allows placement activities to be managed efficiently.

## Objectives

- Maintain student details in one centralized platform.
- Display available placement drives.
- Check student eligibility based on CGPA requirements.
- Track student applications.
- Provide a simple and user-friendly dashboard.

## Key Features

1. **Dashboard:** Displays placement-related information.
2. **Student Management:** Register and maintain student profiles.
3. **Placement Drives:** View available company placement opportunities.
4. **Eligibility Checking:** Check eligibility based on CGPA criteria.
5. **Application Tracking:** Monitor placement application status.
